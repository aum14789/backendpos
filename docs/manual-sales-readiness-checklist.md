## ✅ เช็คลิสต์ 6 ขั้นตอนทดสอบการขายจริง (Step-by-Step Checklist)

### 1. 🔐 Login ด้วย PIN ในโหมด Offline
- **การทดสอบ**:
  1. เปิดแอป Android POS บนเครื่อง
  2. ตัดการเชื่อมต่ออินเทอร์เน็ต (หรือเปิด Airplane Mode)
  3. กรอก PIN: **`1234`**
- **ผลที่คาดหวัง**:
  - ระบบตรวจสอบ BCrypt Hash ออฟไลน์ใน Room Database สำเร็จ
  - ปลดล็อกเข้าสู่หน้าเลือกประเภทการขาย (DINE_IN, TAKEAWAY, DELIVERY, BUFFET) ทันที

---

### 2. 🍽️ สั่งอาหารทานที่ร้าน (Dine-In) ปิดบิลเงินสด และพิมพ์ใบเสร็จอย่างย่อ
- **การทดสอบ**:
  1. เลือกโหมด **DINE_IN** ➔ เลือกโต๊ะ **`T-01`**
  2. กดเลือกเมนู: *หมูคุโรบูตะสไลซ์ (฿180.00)* 2 ที่ + *ชุดผักรวม (฿90.00)* 1 ที่ = ยอดรวม ฿450.00
  3. กดปุ่ม **"ส่งครัว (Send to Kitchen)"** ➔ สถานะเปลี่ยนเป็น `CONFIRMED`
  4. กดปุ่ม **"ชำระเงิน (Payment)"** ➔ เลือกวิธี **`CASH`** ใส่เงินรับ ฿500.00
  5. กดบันทึกชำระเงิน
- **ผลที่คาดหวัง**:
  - คำนวณเงินทอน ฿50.00 ถูกต้อง (5,000 สตางค์)
  - หน้าจอ Preview แสดงใบเสร็จ 80mm พร้อมปุ่ม **"🖨️ พิมพ์ใบเสร็จอย่างย่อ"**
  - ข้อความใบเสร็จมีครบ: ชื่อสาขา, เลขที่ออเดอร์, รายการ, VAT 7% inclusive (฿29.44), ยอดสุทธิ ฿450.00, เงินรับ ฿500.00, เงินทอน ฿50.00

---

### 3. 🥩 สั่งแบบบุฟเฟ่ต์ (Buffet) เลือกโปรโมชั่น นับเวลา Countdown
- **การทดสอบ**:
  1. เลือกโหมด **BUFFET**
  2. เลือกโปรโมชั่น **`Standard Shabu Buffet (฿399.00)`**
  3. ระบุจำนวนลูกค้า: ผู้ใหญ่ 2 ท่าน (รวม ฿798.00)
  4. กดเริ่มรอบบุฟเฟ่ต์ (Start Buffet Session)
- **ผลที่คาดหวัง**:
  - รายการอาหารที่แสดงให้สั่งจำกัดเฉพาะชุด Standard (หมูคุโรบูตะ, ผักสด, น้ำซุป, ชาเขียวมัทฉะ) ในราคา ฿0.00
  - ไม่แสดงเมนูวากิวและแซลมอน (มีเฉพาะในโปร Premium ฿699)
  - แถบสถานะด้านบนเริ่มนับเวลาถอยหลัง (Countdown) 90 นาทีอัตโนมัติ

---

### 4. 🎁 ใส่ส่วนลดมือ (Manual Discount) และตรวจสอบความถูกต้องของยอด
- **การทดสอบ**:
  1. อยู่ในหน้าออเดอร์ กดปุ่ม **`🎁 ใส่ส่วนลด`**
  2. ทดสอบใส่ส่วนลด 5%:
     - เลือกโหมด `%` ใส่ `5`
     - ใส่เหตุผล: *โปรโมชั่นแนะนำร้าน*
     - ใส่รหัสผู้อนุมัติ: `cashier01` ➔ กดยืนยัน ยอดลดทันที 5%
  3. ทดสอบใส่ส่วนลด 15% (>10% ต้องใช้ Manager Override):
     - ใส่รหัสผู้อนุมัติ: `manager01` (Manager PIN 9999) ➔ กดยืนยัน
- **ผลที่คาดหวัง**:
  - ยอด Subtotal, ส่วนลด, VAT 7% Inclusive, และ Grand Total คำนวณตามสูตรคงที่ถูกต้องแม่นยำ
  - มีบันทึกเหตุผลและผู้อนุมัติใน Audit Trail ของออเดอร์

---

### 5. 📡 ออฟไลน์ขายต่อเนื่อง (Offline-First Sync Engine)
- **การทดสอบ**:
  1. ปิด Wi-Fi บนเครื่อง POS Terminal
  2. ทำการเปิดออเดอร์ใหม่ สั่งอาหาร และปิดบิลชำระเงินตามปกติ
  3. สังเกตสถานะมุมจอบันทึกใน `sync_outbox` เป็น `PENDING`
  4. เปิด Wi-Fi เชื่อมต่ออินเทอร์เน็ตกลับมา
- **ผลที่คาดหวัง**:
  - ระบบยิง `POST /api/v1/sync/push` อัตโนมัติภายใน 30 วินาที
  - Backend ตอบกลับ HTTP 200 OK
  - บน Web Backoffice หน้า `OrderHistoryPage` (`/orders`) ข้อมูลออเดอร์ที่สั่งขณะออฟไลน์ปรากฏขึ้นทันที และสถานะใน Outbox เปลี่ยนเป็น `SYNCED`

---

### 6. 💼 เปิด-ปิดกะพนักงานแคชเชียร์ (Shift Variance)
- **การทดสอบ**:
  1. เปิดกะแคชเชียร์ด้วยเงินทอนเริ่มต้น: **฿1,000.00**
  2. ขายอาหารรับเงินสด 2 บิล (รวม ฿750.00)
  3. กดปิดกะ:
     - ยอดที่ระบบคำนวณ (Expected Cash) = ฿1,000 + ฿750 = **฿1,750.00**
     - กรอกเงินนับจริงในลิ้นชัก (Actual Cash): **฿1,750.00**
  4. กดบันทึกปิดกะ
- **ผลที่คาดหวัง**:
  - ผลต่าง (Variance) แสดงเป็น `ZERO` (฿0.00)
  - บน Web Backoffice หน้า `ShiftManagementPage` (`/shifts`) แสดงแถบสีเขียว *"เงินสดตรงตามเก๊ะ (฿0.00)"* สมบูรณ์
